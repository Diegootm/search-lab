# Search Lab

Colección de solucionadores de problemas clásicos de Inteligencia Artificial,
implementados con algoritmos de búsqueda no informada e informada. Proyecto de la
materia Inteligencia Artificial, Universidad Mayor de San Simón (UMSS).

## Descripción

Este repositorio reúne la implementación de varios problemas de búsqueda vistos en
los capítulos 3, 4 y 5. Cada problema se resuelve con una o más metodologías y, en
los casos de entrega, se comparan sus rutas solución según los parámetros de
evaluación: completitud, optimidad, complejidad temporal y complejidad espacial.
